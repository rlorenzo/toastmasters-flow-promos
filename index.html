Six steps.One red lamp.

Google Flow animates the background, where there is nothing to misspell. Everything that has to be exact — names, dates, the disclaimer Toastmasters requires in your opening frames — is rendered locally from HTML and proofread as a still image before a single frame is assembled.

Five steps you can run again for nothing. One you cannot take back.

Go

Deterministic and free. Same inputs, same output, every time. Run it fifty times while you get the wording right.

Hold

The machine has done its part and cannot check itself. A person reads the result before it goes anywhere.

Spend

Costs real credits, returns something different every time, and no amount of prompting makes it trustworthy with text.

Before you start

The repository ships documentation, templates, and a build script — and no assets at all. The Toastmasters logo belongs to Toastmasters International, and the meeting photos are of people who agreed to a club post, not to a public repository. You supply both.

Install and clone

Go 
# macOS; on Debian/Ubuntu use apt, on Windows use WSL
brew install ffmpeg
pip3 install Pillow

git clone https://github.com/rlorenzo/toastmasters-flow-promos
cd toastmasters-flow-promos

Chrome or Chromium is the third dependency — the build script drives it headless to render the text cards, and finds it automatically on macOS and Linux. If yours lives somewhere unusual, pass CHROME=/path/to/chrome.

Drop these into the clone
  • assets/ToastmastersLogoWhite.png — the official white logo, from the members' area of the Toastmasters brand portal. Use the white variant on dark backgrounds, unaltered; the rules are in the Brand Manual.
  • fonts/Montserrat-*.ttf — Regular, Medium, SemiBold, Bold, ExtraBold from JulietaUla/Montserrat (SIL OFL). Montserrat is the Brand Manual's own free alternate to Gotham, which is why it is not a style choice.
  • assets/group_photo.png — your meeting screenshot, untouched.

The chain

Each station names the tool that drives it. Four Claude Code skills ship in this repo under .claude/skills/ and load automatically once you open the clone — tm-meeting-recap runs the whole chain, google-flow covers the credit-spending station, tm-brand knows the compliance rules, and tm-social-post publishes the result. They do the orchestration you would otherwise do by hand: reading the brand manual, checking the Flow dialog before approving it, proofreading the rendered cards.

01

Gather assets

Go
  • Finder / shell
  • agent

Take the Zoom grid screenshot while the meeting is still open. It is the source for both the photo scene and every winner crop, so one good capture is the whole shoot.

One trap worth knowing before an agent hits it: macOS screenshot filenames contain a narrow no-break space (U+202F) before PM. Typing that filename by hand fails; copy by glob instead.

cp ~/Desktop/Screenshot*8.15.17* assets/group_photo.png
02

Generate the background

Spend

This is the only step that costs money and the only one you cannot repeat for free. About 12 credits per 8-second clip. Read the confirmation dialog before approving it — model, duration, count, and especially aspect ratio. The Flow assistant has read 16:9 as 9:16; it was caught in the confirmation dialog, which is the only reason a portrait clip was never paid for.

  • google-flow
  • claude-in-chrome

Most weeks you skip this station entirely. The background carries no meeting-specific content, so last week's clip works for this week's recap — point BG_VIDEO at the file you already have. Any 8-second 16:9 clip with no text and no people will do, generated here or not. For a weekly club this is a week-one cost, not a per-video one.

Google Flow has no public API and no official MCP server, so this step runs in a real browser. That is the reason it is fenced: every other station in the chain is a local process you can re-run, and this one is a paid request to a model that returns something new each time.

You need one clip. The build loops an 8-second background into 15 seconds with a one-second crossfade, so a second generation buys you nothing.

# The prompt that worked first try. Every NO is load-bearing.
Generate ONE 8-second 16:9 video clip using the fastest/cheapest
video model. Subject: an abstract, minimalist, premium corporate
motion background. A deep dark navy blue gradient backdrop, very
slow soft diagonal light rays drifting gently from the upper left,
and a few tiny softly-glowing warm golden dust particles floating
slowly. Elegant, calm, professional. Camera is completely static.
STRICT REQUIREMENTS: absolutely NO text, NO letters, NO numbers,
NO words, NO typography, NO logos, NO symbols, NO people, NO
objects, NO brush strokes forming shapes - purely abstract color
and light only, edge to edge. Audio: soft uplifting instrumental
corporate background music, warm and gentle, no vocals, no
narration, no sound effects.

Describe colour in words, never in hex. A prompt containing #F2DF74 once produced a gold ribbon reading Best #2DF74.

The clip arrives with a usable music bed, which is the other reason one generation is enough — the audio comes free with the video. Save it as assets/bg.mp4.

03

Describe the meeting

Go
  • meeting.conf
  • tm-brand

One file holds everything that changes week to week. Values are HTML-escaped on the way into the templates, so an ampersand in a club name is safe to type literally.

CLUB_NAME="YOUR CLUB TOASTMASTERS"
MEETING_DATE="MARCH 12, 2026"   # full date — meetings are weekly
THEME_LINE1="FRESH"
THEME_LINE2="START"          # empty for a one-line theme
WORD_OF_DAY="ELOQUENT"

WINNER1_NAME="FIRST NAME"
WINNER1_AWARD="Best Speaker"
WINNER1_IMG="assets/winner1_crop.png"

PHRASE="Find Your Voice"   # exactly one approved phrase

Two fields carry compliance weight rather than taste. PHRASE must be one of the approved Toastmasters phrases and only one per video. CREDIT must name the creator, the club, the District, and the copyright year — the Brand Manual asks for all four in the end credits.

Leave WINNER2 and WINNER3 empty and the row re-centres for a single winner; fill all three and the tiles resize to fit.

04

Crop the winners

Go
  • Pillow
  • agent

Cut a landscape tile per winner out of the group photo. The tiles are roughly 1.9:1 to match the card, and the crop box matters for one specific reason: Zoom burns a name label into the bottom-left of every tile. Include it and you have put un-proofread text back into your video — the exact failure the whole pipeline exists to prevent.

python3 -c "
from PIL import Image
im = Image.open('assets/group_photo.png')
im.crop((320, 96, 1080, 498)).save('assets/winner1_crop.png')
"

This is a good task to hand an agent: it can read the photo, find each person's tile, and propose crop boxes that clear the labels — then you look at the PNGs it wrote.

05

Build

Go
  • templates/build.sh
  • tm-meeting-recap
templates/build.sh

Roughly thirty seconds later you have a finished video. The script fills the templates from your config, screenshots them through headless Chrome at 1920×1080 on a transparent background, frames the photo with a rounded white card, and hands six layers to ffmpeg.

It checks every input before rendering anything, and that check exists for a precise reason: Chrome draws a missing image or font as blank space rather than failing. A mistyped crop filename would otherwise sail through and land in the finished cut as a hole where a face should be.

Everything here is deterministic. Changing a name, a date, or a fade time is a re-render, not another generation — which is why it is worth getting the wording right at this station rather than at the previous one.

06

Verify & clear

Hold
  • your eyes
  • tm-brand

The amber lamp is not a formality. Everything upstream is a machine that cannot read, and this is where a person reads.

# substitute whatever OUTPUT names in meeting.conf
# one frame per second, tiled — scan for garbled text
ffmpeg -i Meeting_Recap.mp4 -vf "select='not(mod(n\,24))',scale=640:-1,tile=4x4" \
  -frames:v 1 sheet.png

# audio sanity: mean should sit near -15 dB (silence reads -91)
ffmpeg -i Meeting_Recap.mp4 -af volumedetect -f null - 2>&1 | grep volume
Read before posting
  • Every name spelled the way its owner spells it. Read the PNGs in cards/, not the video — the still is where a typo is actually legible.
  • The disclaimer is readable in the opening frames — 14px or larger at 1080p, 60% white or brighter.
  • No Zoom name label survived into a winner crop.
  • The logo is unaltered and not overlapped, with the club name below it.

What the fifteen seconds are made of

One 8-second clip, played twice with a one-second crossfade, carrying four overlays that fade their alpha channel in and out. Because the background never stops moving underneath, it reads as one designed piece rather than four slides.

0.0 → 3.6
Title
Theme, word of the day, club name under the logo, TI disclaimer
3.6 → 8.2
Meeting
Group photo, static, in a white rounded card
8.2 → 12.0
Winners
One to three tiles with names and awards
12.0 → 15.0
Close
Logo, club name, one approved phrase, URL, credits
00:0000:0500:1000:15

Timing lives in the ffmpeg st= values inside build.sh; content lives in meeting.conf. Both re-render in seconds, so the timing is worth playing with.

Why the red lamp is red

Seven failed generations, recorded rather than deleted. Every one of these was observed, and together they are the argument for keeping generation away from anything that has to be correct.

Observed failure modes, Veo via Google Flow
What was triedWhat came back
A hex colour in the promptThe model rendered the string. A gold ribbon came back reading Best #2DF74.
Quoting text meant for the screenSometimes clean, sometimes soup. A coin flip you cannot afford on a member's name.
Animating a photo containing textZoom name labels and the backdrop slogan were re-drawn as gibberish.
Animating facesIdentity drift. People come back looking subtly not like themselves.
16:9 in an assistant promptRead as 9:16. Caught in the confirmation dialog and corrected before approving — which is the whole reason to read it.
Re-using an old approval dialogSpent dialogs linger in the chat and look clickable but do nothing. Only a fresh one spends credits.

Clearance

Brand compliance here is a requirement rather than a preference, and two of these have nothing to do with Toastmasters at all.

  • Written permission from every person who appears. Guardians for anyone under 18. This one is not about branding.
  • The disclaimer appears in one of the first frames. The title card carries it by default — do not delete it to buy space.
  • Club name below the logo, and end credits naming creator, club, District, and © year.
  • One approved phrase, no more. No drop shadows or word art on type; the logo unaltered and never overlapping a face.
  • Submit the finished video to brand@toastmasters.org for approval before it represents your club in public.

Publishing is deliberately outside the chain. The six stations end at a verified file, because posting is the one action nothing downstream can undo — a misspelled name is a correction, a published misspelled name is a screenshot. The tm-social-post skill drives your own signed-in browser to a Facebook Page and personal LinkedIn, drafts a caption with every name copied verbatim from meeting.conf, and stops for your explicit approval before it clicks anything.
